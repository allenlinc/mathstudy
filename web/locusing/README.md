# 长方体的展开图 · 11 种折法（locusing 交互动画）

用 [locusing](https://www.npmjs.com/package/locusing)（Manim 风格的声明式数学可视化库，
SVG 渲染 + 交互控件）做的可交互网页：孩子可以旋转长方体、亲手把六个面沿折棱拉开，
把小学数学里 11 种经典展开图（1-4-1 ×6、2-3-1 ×3、2-2-2 ×1、3-3 ×1）全部体验一遍。

## 直接使用

双击打开根目录的 `cuboid-nets-11.html` 即可（单文件，已内嵌全部依赖，无需联网）。

操作方式：
- **按住鼠标右键拖动**：上下左右旋转长方体（空白处左键拖动也可以，支持触屏）
- **长按一个彩色面（约 0.3 秒）再往外拖动**：面绕折棱真实翻开，拉多少开多少；
  松手时拉开过半自动摊平，不足半自动合回
- **轻点一个面**：它自己平滑展开 / 合上
- **右侧面板点选折法**：11 种缩略图，点谁折谁；拼平一种会点亮橙点并累计「已体验 n/11」
- 底部按钮 / 快捷键：`全部展开`、`变回盒子`、`复位视角`；`空格` = 展开/变回，`R` = 复位视角

## 目录结构

```
locusing/
├── cuboid-nets-11.html      成品单文件（与 dist/ 构建产物相同，双击即用）
├── src/
│   ├── engine.mjs           展开图引擎：盒尺寸、11 种折法枚举、铰链链几何（纯数学，无 DOM）
│   ├── app.js               渲染与交互：locusing 图元绘制、指针操作、折法切换、补间
│   └── shell.html           页面骨架与样式（含 /*__BUNDLE__*/ 内联占位）
├── test/
│   └── geometry.mjs         几何断言：盒还原 / 六面共面 / 不重叠 / 中间态刚性
├── build.mjs                把 bundle 内联进骨架，产出 dist/ 单文件
├── package.json             依赖与脚本
└── dist/                    构建产物
```

## 常见修改

| 想改什么 | 去哪里 |
|---|---|
| 长方体尺寸（宽/高/深） | `src/engine.mjs` 顶部 `BW / BH / BD` |
| 六个面的颜色 | `src/app.js` 顶部 `COL` |
| 拉开的吸附门槛（默认拉过 40° 松手自动摊平） | `src/app.js` 搜索 `> 40` |
| 折法间切换的动画时长 | `src/app.js` 的 `tweenFace` 调用参数 |

改完后重新构建：

```
npm install
npm run build     # 产物在 dist/cuboid-nets-11.html
npm test          # 跑几何断言（不依赖浏览器）
```

## 实现说明

- 11 种折法不是手写的：`src/engine.mjs` 枚举长方体面邻接图的全部生成树（384 棵），
  按真实尺寸展平并剔除平面重叠的树，再按多连方形状（8 个二面对称像归一化）分类，
  正好得到教材里的 11 类；每类预计算铰链链的相对变换。
- 运行时每面绕与父面的公共棱折动，θ∈[0°,90°]：0° 折起成盒，90° 摊平共面。
- 渲染：六面按深度排序（画家算法）+ 朝向镜头的朗伯明暗，图元与渲染全部走 locusing。
